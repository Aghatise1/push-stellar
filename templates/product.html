Straight answers

Current position
Is Push live?

Push is deployed as a controlled Stellar testnet pilot. It is not a real money service.

Does Push have a token?

No. Push does not require or issue a proprietary token.

Is Push tied to one blockchain?

The current escrow implementation is built on Stellar testnet using Soroban contracts. No additional blockchain integration is promised.

Does Push hold money?

Test tokens are held by the escrow contract. Push never stores private keys. Authorised staff can resolve disputes within the contract rules. Real money use requires further security and legal review.

What is the platform fee?

No platform fee is implemented in the current escrow pilot. Future fees are not yet decided.

Who is building it?

Push is founded by Aghatise. A full public biography and verified contact details should be added before launch.
